# 导游证备考助手 V1

一个面向导游人员资格考试学习场景的轻量 Web App 原型。

## V1 功能

- 四科首页
  - 政策与法律法规
  - 导游业务
  - 全国导游基础知识
  - 地方导游基础知识
- 单科练习
- 随机练习
- 单选题、判断题
- 自动判断对错
- 答案解析
- 错题本
- 收藏数据结构
- 学习统计：累计作答、答对数量、正确率、错题数量
- localStorage 本地保存学习数据
- iPad / 手机响应式界面
- 不需要 Ollama
- 不需要后端
- 不需要安装 Node.js

## 最简单的使用方式

直接打开 `index.html` 即可体验。

## 发布到 GitHub Pages

1. 把 `index.html` 和 `README.md` 上传到 GitHub 仓库根目录。
2. GitHub 仓库进入 `Settings` → `Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/ (root)`。
5. 保存后等待 GitHub Pages 发布。
6. 以后打开 Pages 地址即可在 iPad 上使用。
